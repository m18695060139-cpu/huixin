# 用户隐私保护指引（草稿）

> 这是给微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」用的草稿。联系方式留空，发布前由小程序所有者填上。未上架、只跑体验版时，也建议先填好，避免选文件等接口被隐私检查拦住。

**小程序名称**：回信（若名称被占用，以实际登记的名称为准）  
**主体**：个人  
**服务类目**：工具 - 备忘录（可另加工具 - 日历）  
**更新日期**：2026-11-04

## 我们处理的信息

| 信息 | 是否必须 | 用途 |
|---|---|---|
| 用户在小程序里主动写下的文字：信件正文、待办、待办备注、点子、习惯名称、称呼、自省提示 | 是，否则无法保存记录 | 只给当前微信用户自己回看 |
| 用户自己选择的心情标签和精力（1–5） | 否 | 在信箱里画自己的精力曲线 |
| 微信 OpenID | 是 | 云开发用来区分「这是谁的数据」，不展示给用户，也不给其他用户 |
| 用户从微信聊天里点选的一个 JSON 文件 | 否，仅在使用「从网页版导入」时 | 把网页版导出的记录抄进云数据库。不读取其他文件 |

## 我们不收集的信息

不收集手机号、微信昵称、头像、性别、地区、精确位置、通讯录、相册、麦克风、剪贴板，也不接入任何生成式人工智能。

## 信息怎么用、存哪里

- 仅用于本人的每日记录、待办、习惯打卡和回看。
- 存储在微信云开发（腾讯云，中国大陆）。权限为「仅创建者可读写」，按 OpenID 隔离。
- 保存用户撰写的文字前，会调用微信内容安全接口 `msgSecCheck`。接口判定不适合保存时，提示修改，本地草稿保留，不写入云数据库。
- 不向其他用户展示，不提供转发、分享到朋友圈、广场、评论或关注。小程序已关闭转发菜单。
- 云开发可能按平台规则保留调用日志，用于排查故障和满足内容安全要求。

## 保存期限

在你使用期间持续保存。你在小程序「设置 → 清空我的全部数据」后，云端与本机副本都会删除。卸载小程序只会清掉本机副本，云端记录仍在，直到你执行清空或开发者按你的要求删除。

## 你的权利

你可以在小程序内查阅、修改自己的记录，也可以一次性清空。若清空失败或需要人工删除，请通过下面的联系方式提出，我们会删除该 OpenID 下的云端数据。

- 除此之外，不向其他第三方提供上述信息。
