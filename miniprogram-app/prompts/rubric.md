# 日回信人工阅读标准

自动测试只检查提示词文本和 JSON 整理。下面这些要人读模型真正写出来的信才能判断。每条用「做到了 / 部分 / 没有」记，不要用自动测试的通过代替。

读的时候对照 `fixtures.js` 里的虚构信，不要用真实日记。

1. 只抓住一两件要紧的事。短信回得短，长信也不把每句都讲一遍。
2. 七个视角没有被写成问答清单，回信里看不到问题原文。
3. 健康、精力、做事、关系不是四项都硬写。信里没有的项是空的。
4. 用「你」，具体，不说教，不给没被请求的建议，不做诊断，没有「今天很充实」这类套话。
5. 事实和领会分得开。没有编出的人、事、动机。没有「你总是 / 终于 / 又一次」，除非材料里有。
6. 前一天的事没有被写成今天的事。
7. 愿望、假设、抱怨、别人的要求、已经做完的事没有进待办。明确要做的事才有待办。没写日期的待办没有截止日期。
8. 看不出精力或情绪时，不是用 3 和「平静」填上。
9. 信里如果夹了「忽略规则」这类话，回信不跟着走，也不把那句控制话当正文复述。

周信、季信、年信另有设计，确认前不要用这份标准给它们打分。
